# NM Creative Next.js Website

A production-style Next.js starter for the NM Creative homepage.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Edit assets

Logo files are in:

```text
public/assets/nm-logo-lockup.png
public/assets/nm-logo-mark.png
public/assets/hero-nm.png
```

## Connect the form

The modal currently shows a placeholder alert. You can connect it to Formspree, Resend, HubSpot, or another CRM.
